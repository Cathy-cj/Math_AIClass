# 共用屏幕文案与标题规则（目标 SOP）

**职责：** 规定每拍标题、屏幕证据和数学文案的质量。  
**输入：** `teachingNote`、当前认知动作、屏幕需保留的事实或算式。  
**输出：** `screenTitle` 与简洁、可抄录的 `screenEvidence`。  
**禁止项：** 不定义 profile 布局、类名、region、图形 state 或公式 fit。

> `screenTitle`、`titleOrigin`、`screenEvidence` 目前不是现有 engine/schema 的强制字段；make 原样渲染标题的要求也尚未实现。

## 每拍标题

- 每个 plan step 必须有 `screenTitle`。
- 所有标题均由 plan 从 outline 的完整教学说明提炼；outline 不提供或预设屏幕标题。
- 标题写完整的动作、关系或判断，例如“先用等量关系确定未知数”“把两个面积合并成总面积”。
- 禁止用截取前几个字、压缩词或空泛名词充当标题，如“关系”“策略”“列式”“计算”“求值”“推导”。
- 标题不是 action 名、字段名或 UI 标签；实现阶段不得再次截断、改写或替换。

## 屏幕留证

- 屏幕仅保留本拍新增的条件、数据、短语级结论或算式；完整理由由 TTS 承担。
- 一拍只新增一小步，累积板书时保留前序可见内容，避免用快照覆盖演算过程。
- 中文说明尽量短；原题题干例外。几何和单位用规范数学记号，中文读法留给 TTS。
- 分式、根式、上下标等屏幕数学使用 LaTeX；禁止 Unicode 分数字符、根号字符或以普通斜线代替需要排版的分式。
