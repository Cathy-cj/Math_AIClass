# 共用 TTS 与话术规则（目标 SOP）

**职责：** 规定逐字口播、话术复用和互动揭晓语气。  
**输入：** 每拍教学意图、`teachingNote`、互动内容及根目录 [phrase-bank.json](phrase-bank.json)。  
**输出：** 每个 step 的 `agent.description` 与可追溯的 phrase 使用记录。  
**禁止项：** 不定义屏幕标题、互动数据结构、profile UI 或动画细节。

> 根 `phrase-bank.json` 只收录三仓文本完全一致的可共用数据。`opening.example`、`opening.practice` 等存在“图/算式”等 profile 变体，暂不伪造统一数组。

## TTS 逐字稿

- `agent.description` 只写教师真正说出口的话：中文汉字与中文标点；数字、字母、公式、单位和数学符号均写成自然读法（几何点名的大写字母除外）。
- 屏幕选项用字母标记时，口播按位置说“第一项”至“第四项”，不得把 A、B、C、D 擅自改读为“甲、乙、丙、丁”；只有题目原始选项本来就是甲、乙、丙、丁时，才能这样读。
- 屏幕中的 LaTeX、阿拉伯数字和数学式不得复制入口播；例如 `$\\frac{1}{3}$` 口播写“三分之一”。
- 分数一律按“分母分之分子”读：`$\\frac{a}{b}$` 读“b 分之 a”；分子、分母均写汉字读法，禁止写成“一分之三”这类倒置说法。
- 分母是运算式时，先完整读出分母再读“分之”：`$\\frac{1}{3\\times4}$` 读“三乘四分之一”，不得按“每三分之一乘四”等方式拆读。
- 不写括号说明、屏幕提示、动画指令或制作备注；这些分别属于屏幕证据、图形规格或 `moduleNote`。
- 一拍只承载一个讲解节奏；口播过长时先拆拍，不能把多个认知跃迁连读。

## 话术组合

- 开场、转场、互动揭晓和练题衔接优先复用根 `phrase-bank.json`；记录 phrase id，避免同一 plan 重复或相邻起首雷同。
- 需要 profile 特有变体时，显式标注来源和适用 profile；不得暗示存在隐式旧文件依赖，也不得把不同文本硬合并成同一 id。
- 禁用 phrase-bank 的 `banned` 内容、导演腔和“难度播报”等播报腔。
- 话术用于连接本题具体理由，不能替代题目条件、推导或结论。

## 互动揭晓

- 问步口播给出必要铺垫后发问。
- 答步只中立揭晓标准要点并推进讲解；不得评价学生对错，也不得假定学生答对。
- 互动的题面、选项、空格和答案由 `interactions.md` 规定；本文件只约束说法。
