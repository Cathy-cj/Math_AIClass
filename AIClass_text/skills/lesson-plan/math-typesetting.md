# 数学排版规范（LaTeX）

课件已有 `AIClassLatex`（KaTeX）。所有屏幕数学表达统一使用 `$...$`，不要用 Unicode 数学符号模拟排版。

## JSON 约定

- JSON 中反斜杠写成 `\\`
- 数学表达放 `$...$`；中文说明、单位放公式外
- 判题字段保持稳定值，不把 LaTeX 当答案 id

```json
{
  "options": [
    { "value": "A", "label": "A. $\\frac{1}{2}$" },
    { "value": "B", "label": "B. $\\frac{1}{3}$" }
  ],
  "answer": "B"
}
```

## 常用写法

| 含义 | JSON 字符串 |
|------|-------------|
| 二分之一 | `"$\\frac{1}{2}$"` |
| 根号 2 | `"$\\sqrt{2}$"` |
| 三次根号 8 | `"$\\sqrt[3]{8}$"` |
| 平方 | `"$r^2$"` |
| 下标 | `"$V_1$"` |
| 圆周率 | `"$\\pi$"` |
| 乘号 | `"$3\\times4$"` |

## 禁止

- `½`、`⅓`、`¼` 等 Unicode 分数字符
- 用 `1/2` 代替需要竖式展示的分数
- 用 `√2` 代替 `$\sqrt{2}$`
- 在 `value` / `answer` 中塞入仅用于显示的 LaTeX

口播 `agent.description` 可写“三分之一”“根号二”；上述限制针对 `push`、选项、快问快答等屏幕文案。
